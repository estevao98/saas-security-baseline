Conteúdo mínimo

Cada arquivo de fontes deve informar:

título da fonte;
organização responsável;
URL oficial;
data de acesso;
versão ou edição, quando confirmada;
tópicos do chunk apoiados pela fonte;
observações sobre incertezas, versões ou acesso restrito.
Regras
Priorizar fontes oficiais indicadas em AGENTS.md.
Não inventar versões, requisitos, comandos ou referências.
Não copiar trechos longos de normas ISO ou ABNT.
Registrar sínteses e a finalidade prática de cada fonte.
Não incluir segredos, credenciais, dados pessoais, URLs internas ou evidências sensíveis.
Não usar o arquivo de fontes como local para relatórios crus.
Atualizar o arquivo do chunk quando uma fonte for adicionada, substituída ou invalidada.
