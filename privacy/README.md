# Privacidade

## Objetivo

Organizar documentos técnicos de privacidade e LGPD sem transformar este repositório em registro real de tratamento.

Os arquivos `privacy/*.md` ainda pertencem ao Lote 8. Até lá, a fonte canônica é `../docs/lgpd-privacy-program.md` e os templates em `../templates/`.

## Regras

- Não decidir base legal automaticamente.
- Não registrar dados pessoais reais, pedidos de titulares, contratos, comunicações à ANPD/titulares ou incidentes reais.
- Usar categorias, IDs opacos e exemplos fictícios quando algo for versionado.
- Levar registros reais para sistema restrito do SaaS consumidor.

## Pendências

- O Lote 8 deve reconciliar `privacy/*.md`, definir artefato canônico por assunto e manter decisões jurídicas como humanas.
